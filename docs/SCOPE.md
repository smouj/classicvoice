# v0.1 product contract

## User story
As a Windows user, I can type Spanish text, choose/tune a classic synthetic voice preset, preview it locally and export the result as WAV.

## Acceptance criteria
1. Four neutral starter presets are available.
2. Speed, pitch and amplitude can be adjusted.
3. Preview produces and plays a local WAV on Windows.
4. Export writes a WAV chosen by the user.
5. No network request is made.
6. Missing eSpeak NG produces a clear error instead of a crash.
7. No proprietary Loquendo voice files or branding are bundled.

Anything not required by these criteria is outside v0.1 unless it fixes a blocker.
