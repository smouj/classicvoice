# Roadmap

## v0.1 — Classic TTS utility

- [x] Text editor
- [x] Four starter presets
- [x] Speed control
- [x] Pitch control
- [x] Volume control
- [x] Preview
- [x] WAV export
- [x] Offline-only operation

## v0.2 — Practical polish

- [ ] Remember the last preset
- [ ] Pronunciation replacements
- [ ] Additional curated eSpeak NG presets
- [ ] Optional normalization before export

## Later, only if justified

- [ ] Piper as a separate natural-voice mode
- [ ] Batch dialogue export
- [ ] Subtitle timing helpers

ClassicVoice will remain a focused TTS utility, not a DAW.
