# Security policy

Please do not publish security vulnerabilities in a public issue. If GitHub's private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. Otherwise contact the maintainer through the [smouj GitHub profile](https://github.com/smouj).

ClassicVoice is designed for local processing. Changes must not add hidden network requests, telemetry, credential collection, remote code execution, or automatic uploads. Report the affected version, impact, and a minimal reproduction; do not include private text or WAV files.
